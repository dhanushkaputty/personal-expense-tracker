# 💰 Personal Expense Tracker

A simple Flask web application to track personal expenses. Users can add, update, and delete their expenses while viewing them in a neatly formatted table.

## 🚀 Features

- Add new expenses with details like date, category, and amount
- Edit or delete existing entries
- View a full list of all your tracked expenses
- Responsive frontend using HTML/CSS and Flask templates
- MongoDB used for storing data

## 🛠 Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** MongoDB
- **Version Control:** Git & GitHub
